# 功能说明（0.6.5）

[English](FEATURES.md) · [返回首页](../README.zh-CN.md) · [安装与启动](INSTALL.zh-CN.md)

## 文稿与编辑器

- 打开本机 UTF-8 `.tex`、`.md`、`.markdown`，直接编辑并自动保存到原文件；切换文件会先保存，遇到冲突或待处理建议会保留草稿。
- 标准、Vim、Emacs 三种编辑模式；语法高亮、撤销/重做、行号、当前行或选区注释/取消注释。
- LaTeX 命令与环境补全，自动配对 `\begin` / `\end`；常用命令及当前文稿中的自定义名称可参与补全。
- 光标位于公式内时显示本地 KaTeX 公式预览；支持部分直接声明的宏，不执行完整 TeX 宏系统。
- 搜索和替换支持大小写、正则、整词、仅选区；浏览上一个/下一个匹配，全部替换可一次撤销。
- 源码字号 10–32 px，可用 Ctrl + 滚轮调整；源码、预览分栏比例可拖动调整。

## 本地 PDF 编译与阅读

- 使用已有 XeLaTeX / pdfLaTeX，识别文稿开头的 TeX 引擎指令；支持 BibTeX，尚不支持 Biber。
- 手动保存并编译、自动编译开关、编译状态及日志、错误行提示、下载正式 PDF；协作模式默认手动编译。
- Windows 编译、BibTeX、引擎/包查询与 SyncTeX 均后台运行，不创建命令窗口。
- 自带 PDF.js，按需渲染可见页；章节目录、页码与滚动手柄、缩放、页面拖动，刷新预览保留阅读位置。
- 源码到 PDF、PDF 到源码双向定位，支持项目内子文件；编译失效后停用旧位置映射。
- PDF 文字拖选与空白处矩形框选；Space 临时拖动，Space + Alt + 左键拖动连续缩放，范围 30%–500%。
- 选区可添加 AI 批注，公式定位保留完整源码边界；重复内容、跨文件或无法可靠匹配的选区会提示重新选择。

## Markdown 与 Obsidian

- 默认使用本地 HTML 实时预览，支持标题、列表、代码块、表格、KaTeX 公式及 Obsidian 图片引用。
- 可切换为本地 XeLaTeX PDF 预览，支持 callout、双链显示文本和 TikZ 代码块；需要本机已有相应 TeX 包。
- 转换时跳过 YAML frontmatter，临时 TeX 与图片副本放在构建目录，不改写原笔记。
- HTML 图片支持 PNG/JPG/GIF/WebP/AVIF；PDF 图片支持 PNG/JPG/PDF，其他格式显示提示。
- 实时预览正文可拖选后右键添加 AI 批注或文字注释；图片/表格的文字注释锚定对应源码块。
- 实时预览使用浏览器文字选择，不提供 PDF 矩形框选；歧义选区需缩小范围或在源码操作。
- 协作模式图片限制在项目内；单用户模式可查找笔记所在的 Obsidian 库。

## AI 批注与逐处校对

- 顶部始终显示“AI 批注 · 数量”，点击查看、编辑或删除批注；可先收集多条，再批量 Send。
- 使用本机已登录 Codex CLI，可选择可用模型与思考等级；支持停止请求，后续 Send 只发送未生成建议的批注。
- 建议在源码显示红色原文、绿色修改，每处独立 Keep / Undo；预览不写入原文，Keep 保存该处修改，Undo 保留原文。
- LaTeX 建议可生成临时红绿 PDF，页边 Keep / Undo 与源码共享操作；正式 PDF 下载仍导出正式文稿。
- 编辑器校对与 PDF 校对可分别开关；关闭不会自动接受或丢弃已有建议。Markdown 使用编辑器校对。
- Style 支持“无”、Tao Compact / Shelah Compact 中英文预设及 UTF-8 提示词导入；默认风格跨文稿保存，每条批注保留自己的快照。
- 支持可选 LaTeX 修改标记色；Markdown 修改不插入 TeX 颜色命令。
- Codex 浏览器支持时，可将源码选区加入主对话的原生批注；它与插件本地 AI 批注列表独立。

## 项目问答与外部修改校对

- 选区右键在侧边项目聊天中提问；项目内文件共享持久聊天记录，可新建对话、停止生成、将回答应用到未变化的选区。
- 单用户模式可按启动时的会话 ID 读取相关主对话上下文；协作模式不附带启动服务的主对话。
- 可选“项目修改校对”跟踪主对话或外部工具已经写入的 `.tex` 修改，在源码及临时 PDF 中逐处 Keep / Undo。
- 外部校对基线和待确认修改跨刷新、重启保存；开关默认关闭，不能在外部工具写盘前拦截。

## 多用户协作与权限

- 所有者生成每人独立的可编辑或只读邀请，分配姓名和颜色；可随时撤销，已撤销成员不显示在活动邀请列表。
- 页面显示在线状态，约每秒同步；非重叠编辑自动合并，同段冲突保留本地草稿并要求明确处理，不采用最后写入覆盖。
- 源码覆盖层显示修改作者颜色，悬停显示姓名，历史保存作者归属；正式 PDF 不加入协作作者颜色。
- 所有者与可编辑协作者可编译固定主文件；编译不需要 Codex 授权。只读成员只能查看或下载已有 PDF。
- Codex 权限由所有者逐人分配，新增协作者默认未授权，只读成员不能获授；后端每次校验聊天、AI 批注、模型列表、摘要和新翻译请求。
- 撤销邀请或 Codex 权限会停止该成员正在运行的 AI 请求；授权成员只管理自己的任务，所有者可管理全部任务。
- 授权使用所有者的 Codex 额度，当前没有逐人额度上限，已消耗额度不会回退。

## 共享文字注释

- 文字注释不调用 AI；从源码、PDF 文字选区或 Markdown 实时预览添加。
- 顶部“注释”面板显示当前文件的讨论、引用、作者、颜色和回复，可定位、解决、重新打开或显示已解决讨论。
- 编辑成员无需 Codex 权限即可评论与回复；只读成员只能查看，作者或所有者可解决讨论。
- 注释保存在协作数据库，不插入论文源码；轮询保留未发布的评论与回复草稿。
- 原文变化或引用重复时不猜测位置；PDF 图片应在对应源码添加注释。

## 项目文件管理

- 浏览项目树，切换项目内已有文件；可编辑成员可修改 UTF-8 `.tex/.md/.markdown/.bib/.sty/.cls/.txt/.csv/.json`。
- 所有者可新建文件/文件夹、多文件上传、替换、重命名及删除；所有协作者可下载单文件或项目 ZIP。
- 单文件上传最大 16 MiB，项目上传与 ZIP 最大 128 MiB；ZIP 排除隐藏历史及回收区。
- 删除移入项目私有回收目录，可在磁盘手动恢复；文件夹只能删除空目录。
- 阻止项目越界、隐藏路径、符号链接/目录联接及 Windows 特殊路径；禁止删除或重命名主文件及在线正在编辑的文件。
- 替换、重命名和删除校验版本；重命名不会自动更新 LaTeX 引用或迁移旧路径历史/注释。

## 多项目统一入口与网络

- 一个网关端口承载多个项目，按 `/p/<项目标识>/` 分发；私人本地管理入口可选择项目或添加本机文稿。
- 每个项目独立保存邀请、会话、文件边界、历史及 Codex 权限；邀请链接自动进入对应项目，协作者不获得其他项目列表。
- 管理登录限制在本地监听地址入口，公网 Host 不能使用管理 API；管理会话在重启后重新登录。
- 默认监听回环地址；显式局域网 IP 或 `--host auto` 可开放 LAN，`--port auto` 优先尝试 8765，占用时绑定系统分配的空闲端口。
- 明确指定数字端口时保持固定；穿透需映射实际监听端口并配置准确公网 URL，保留 Host，严格校验 Host / Origin，不自动配置防火墙或穿透。

## 中文阅读翻译

- 按项目选择开启，默认关闭；PDF / Markdown 右侧显示中文译文，可关闭跟随滚动，下载中文阅读副本。
- 首次翻译已有英文段落，保存/编译后延迟合并更新，仅处理变化或缺失段落；内容缓存可跨移动、恢复和重启复用。
- 译文文件和缓存保存在项目私有目录，不覆盖原文，不属于正式 PDF；失败保留已完成译文，关闭停止任务但不清缓存。
- 新翻译需要 Codex 授权；未授权协作者只能阅读缓存，不能通过保存或直接请求触发翻译。
- Markdown 按源码段落对齐，PDF 按当前页文字对齐，无法匹配时按阅读进度同步，不保证逐句对应。
- TeX 读取项目内静态 `\input` / `\include`，不扩展动态宏或读取外部文件/`.bib`；Markdown 跳过 frontmatter、代码及参考文献。
- 每批最多 12 段/12000 字符，总量最多 100 万字符/2000 段；首次整篇翻译仍消耗额度。

## 历史与个性化

- 项目历史覆盖主文件与子文件，显示文件名、章节、时间、作者及 AI 修改要求；源码差异、版本恢复与 PDF 改动对比。
- PDF 历史按完整修改句子标红，支持跨页；按需生成对比图片并缓存，普通编译不保存完整历史 PDF。
- 历史摘要可通过 Codex 后台生成，按版本/基线/界面语言缓存；失败仍显示本地章节信息。协作历史操作由所有者执行。
- 八种界面语言、标准/Vim/Emacs、14 种明暗主题、自定义主题、修订颜色、字号、目录样式与分栏比例。
- 上传或粘贴截图可本地提取配色并保存主题，不调用 AI，不上传截图；主要偏好跨文稿和端口保存。

## 使用边界与已知检查结果

协作面向可信合作者。网页路径限制不等于操作系统沙箱：可编辑成员编译恶意 TeX 仍可能读取本机其他文件。项目内普通文件和历史对成员可见，应选择专用项目目录。登录凭据不提供给网页；邀请和会话使用散列及 HttpOnly cookie，HTTPS 会话使用 Secure。公网使用须启用协作认证和有效 HTTPS。

当前 Windows 已实机验证；macOS 路径与选择器有模拟检查，仍需真机验证。已有 TeX 与相关包由使用者准备。复杂宏、重复文字和特殊版式可能影响定位、翻译或 PDF 差异；0.6.5 维护检查中，Markdown PDF 范围定位及综合编辑器资源加载断言尚有未通过项。后台编译、BibTeX、包发现和 SyncTeX 的独立实际编译检查通过；这里不宣称整个检查集全部通过。
